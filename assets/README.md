# README figures

These figures are rendered from the author-provided SCOPE Overleaf sources (`SCOPE_w_w_w.zip`). The main manuscript is `sigconf.tex`.

- `motivation.png`: upper motivation panels of `figure/scope-intro-overview.pdf` (paper Figure 1).
- `framework.png`: `figure/method.pdf` (paper method overview).
- `unseen-generalization.png`: `figure/scope-unseen-generalization.pdf`.
- `ablation-success.png`: `figure/scope-ablation-success-compact.pdf`.
- `response-steps.png`: `figure/scope-response-steps-compact.pdf`.

Images are rasterized directly from the supplied PDFs. Experimental values in the README follow the main-results table embedded in `sigconf.tex`; the separate `table/main-tab.tex` is not used by that manuscript. Main results use step 150, and ALFWorld ablations use step 180.

## Project identity

- `scope-mascot.png`: author-supplied SCOPE mascot, shared with the project website.
- `scope-logo.svg`: editable SCOPE wordmark using the project website's blue, violet, pink, gold, and teal palette.

- `bounded-opsd.svg` and `pairwise-reward.svg`: formula vectors typeset with MathJax. Their SVG descriptions retain the LaTeX source; the README displays the vectors directly.
